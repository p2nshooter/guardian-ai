Developer Reference

AXTO Edge — AI Gateway, BYOK Management & Multi-tenant API Platform

📡
Proxy Endpoints
Drop-in replacement for OpenAI, Anthropic, and other AI providers. Point your SDK to Edge and it handles routing, rate limiting, and billing automatically.
👥
Customer Management
Create customers, issue API keys, set plans, and track usage per customer. Full lifecycle management via REST API or the dashboard.
💎
Billing Plans
Define tiered plans with RPM limits, token quotas, model access lists, and markup percentages. Auto-generate invoices monthly.
🛡
Content Firewall
Block prompt injections, NSFW content, and policy violations before they reach your AI provider. Configurable per plan.
